User Manual

Public guide for the current iPhone release. The in-app manual includes localized screenshots and the same operating principles.

App lock

Set a six-digit PIN, letter password, or 3×3 gesture in Settings. You may enable system authentication first and choose an inactivity timeout. Store the app-lock secret separately from vault recovery credentials.

Passwords

Choose Passwords from the left drawer, then use +. Add one or more app/domain services, username, password, expiry, and notes. Use the generator for length and character-set controls. Groups start collapsed and can be reordered; entries support swipe actions. Favorite important records for quick filtering.

Password health

The shield action checks weak, reused, expired, expiring, and incomplete records locally. Optional breach checks use a k-anonymous prefix request and cache the result until the password changes or the cache expires. A green safe badge only describes the checks that have actually completed. At-risk details can open a related website or app so you can change the password at its source.

Trash and password history

Deleting a password moves it to Trash for 30 days. Restore it to its original group or permanently delete it after confirmation. When a password changes, passmgr keeps up to ten distinct previous passwords; viewing, copying, clearing, restoring, and permanent deletion remain protected by App Lock.

Authenticator

Add TOTP/HOTP by camera, a QR image, otpauth URI, or manual secret. Tap or long-press a code to copy it. HOTP counters synchronize conservatively; take over only after confirming the server’s counter.

Wi-Fi credentials

Save or edit network name, security type, and password. Current-network discovery cannot read the Wi-Fi password from iOS, so enter it before applying or sharing. The detail QR code lets another compatible device join.

Passkeys

Passkeys appear as their own vault space. Supported websites and apps can ask the passmgr credential provider to create or use a passkey. Passkey private keys never appear in plaintext exports; encrypted synchronization and recovery use the same vault protection model.

AutoFill

Enable passmgr in iOS Password Options. Matching app/domain candidates can appear in the keyboard or system picker. Selecting an exact record performs required authentication and fills it; open passmgr when you need search, browsing, or creation.

Import and export

Use the data-exchange button on the Passwords page. Portable vault exports are encrypted and require a separate file passphrase. Apple Passwords CSV imports are accepted through supported file/share flows. Review the preview before writing: new, duplicate, conflicting, and invalid records are separated, and no password is imported until you confirm. Never upload plaintext exports.

Remote backup and synchronization

Set a mandatory recovery credential under Sync Security before adding a remote destination. The single primary target performs two-way synchronization; enabled secondary targets receive encrypted backups only. Manual and automatic operations use the same encrypted synchronization path.

Recovery

After a fresh install, passmgr can detect its iCloud Keychain snapshot. Restore with the original recovery passphrase or recovery-key file. If Device Trust protected the snapshot, also import the previously exported encrypted device identity.

Appearance, language, and reset

Settings controls system/light/dark display, theme family, toolbar style, and supported language. Reset Local Data retains remote objects; Reset All Data attempts to remove both local and configured remote data. Both require authentication.

Safety

Keep encrypted exports and recovery credentials in separate secure locations. Test restoration before depending on a backup. Contact support without sharing secrets.
